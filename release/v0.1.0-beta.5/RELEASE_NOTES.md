# PolyScribe (声织纪要) v0.1.0-beta.5 发版说明

PolyScribe `v0.1.0-beta.5` 是一次以**现代化系统架构重构、端侧模型中枢升级、多端窄屏自适应与存储空间全景治理**为核心的里程碑式更新。本次更新将原本臃肿庞杂的系统设置重构为规范、优雅的二级子菜单体系，全面重构升级了端侧离线模型管理界面，引入了中英文排版智能清洗器，优化了 Windows WASAPI 采集与无边框桌面交互，并针对 320px/360px 极窄移动设备屏幕实现了全方位防溢出适配，全量 65 项自动化测试 100% 绿灯通过。

---

## 🚀 核心更新亮点

### 1. 系统设置架构模块化全面重构
- **解耦巨型单页**：将原本超过 1400 行代码的单体设置页面彻底解耦，重构成职责分明的现代化二级导航结构。
- **四大专业设置子页**：
  - **存储空间与数据清理** (`StorageSettingsScreen`)：全景可视化展示应用数据、音频录音、离线模型与临时缓存占用，提供多维度安全清理。
  - **音频采集与偏好设置** (`AudioSettingsScreen`)：精细化配置麦克风与系统内录偏好、采样率与录音质量。
  - **开放 API 与局域网服务** (`ApiServiceSettingsScreen`)：一键启停本地 HTTP 转写端口与 mDNS 局域网服务广播，提供实时 API 调用测试与生态接入指引。
  - **全局快捷键与关于系统** (`ShortcutsSettingsScreen`, `AboutScreen`)：定制桌面端全局热键，展示版本历史、检查更新与离线说明。

### 2. 端侧模型管理中心 (Model Hub) 重构升级
- **卡片化现代视觉交互**：全面重构模型卡片 UI，清晰展示 SenseVoice-Small、Whisper-Base/Tiny、CAM++ 声纹识别及 Silero-VAD 模型的技术规格、量化格式与磁盘体积。
- **多镜像加速与下载鲁棒性**：深度整合官方 GitHub Releases 与 ModelScope 国内高速镜像源，支持实时下载进度百分比、网络异常智能重试与自动校验解压。
- **健康状态可视化**：实时监测各项离线 AI 模型的就绪状态与完整性，一键检测模型损坏并支持自动修复。

### 3. 中英文排版智能清洗器 (`TranscriptCleaner`)
- **消除汉字夹杂空格**：针对部分 ASR 模型在汉字间输出多余不规则空格的问题，进行高精度智能清洗。
- **保护专业混排**：严格保全中英文混排间距（如 `PolyScribe 纪要`）以及英文原生单词之间的标准空格，避免单词粘连。
- **口吃与连续叠字收敛**：智能平滑口吃发音，大幅提升纪要段落的阅读流畅度与导出质量。

### 4. 移动端极窄屏幕响应式防溢出优化
- **全屏自适应无死角**：针对 320px 与 360px 极窄宽度手机屏幕，全面优化模型管理、播放器操作栏、快捷键列表以及弹窗布局。
- **彻底消除黄色溢出斑马线 (A RenderFlex overflowed)**：优化长标题排版、自适应软换行与弹性空间伸缩，保障各类移动机型的舒适体验。

### 5. Windows 桌面原生引擎与视窗优化
- **WASAPI 音频引擎鲁棒性**：增强 Windows 底层音频设备枚举、系统内录混音与缓冲区同步，大幅降低极端高负载下的丢帧风险。
- **桌面视窗与生命周期适配**：完善桌面端窗口大小记忆与原生标题栏适配。

### 6. 自动化测试套件扩充与质量门禁
- **用例扩充至 65 项**：新增窄屏响应式布局测试、TranscriptCleaner 智能排版清洗测试、存储服务管理单元测试，覆盖率进一步提升。
- **100% 绿灯保障**：全量 65/65 项自动化测试全部通过，保证生产发版零潜在回归风险。
