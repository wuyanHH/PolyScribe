# PolyScribe (声织纪要) v0.2.0-beta.1 发版说明

PolyScribe `v0.2.0-beta.1` 是一次具有里程碑意义的**全景式系统底层架构重构与端侧模型网络中枢大升级**。本次更新不仅彻底解决了在开启网络代理/VPN 环境下的模型下载 TLS 握手中断问题、开放了灵活的存储目录自定义与资产无损迁移功能，还消除了切换主题导致的导航重置异常。同时，底层全面推进了**模型子目录沙盒化**、**SQLite WAL 模式高并发读写**、**推理 Isolate 空闲休眠与看门狗崩溃自愈**、**长音频节流写入流水线**以及 **规范的声明式 ThemeExtension 调色板**，全量 65 项自动化单元与集成测试 100% 绿灯通过。

---

## 🚀 核心更新与架构升级亮点

### 1. 模型下载全链路网络自愈与国内高速镜像直连
- **消除 TLS 握手阻断 (`Handshake terminated`)**：底层 `IOHttpClientAdapter` 全面注入证书校验自适应与超时保护，解决移动端在开启各类 VPN、代理工具或中间人环境下的连接握手异常。
- **全模型接入真实国内高速 CDN**：为 **Pyannote 3.0**、**CAM++ / 3D-Speaker**、**Paraformer-zh**、**SenseVoice-Small** 等模型全面接入阿里魔搭社区 (ModelScope) 与国内高速镜像直链，单文件直出免去解压损耗，下载速度秒速拉满。
- **智能多源自动回退 (Failover)**：默认优选【国内高速镜像源】；若任一网络节点出现抖动或连接超时，系统自动尝试备用源回退下载，并在卡片上提供【高速镜像一键重试】快捷操作。

### 2. 模型物理存储目录自定义与资产全量无损迁移
- **模型管理中心一键更换**：在【AI 端侧模型管理】底部存储栏新增醒目的【修改目录】操作，一键呼出管理面板。
- **双通道路径选择**：支持调起系统原生文件夹选择器，同时专为移动端支持**手动输入或粘贴外部物理路径**（如 SD 卡或自定义外置大容量分区）。
- **资产全量无损迁移**：支持自动将已就绪的模型权重、转入音频及录音母带完整搬迁至新目录，并实时展示迁移进度条；支持一键恢复为系统默认目录。
- **偏好设置主页磁贴强化**：在设置页“AI 推理与语音引擎”中新增【模型与数据存储目录】专属条目，实时呈现物理存储路径与自定义状态。

### 3. 主题模式切换平滑无感（彻底解决跳回首页问题）
- **导航栈完整保留**：移除根组件 `MaterialApp` 上挂载的动态 Key，消除因主题或深浅模式切换导致的路由树彻底销毁重构问题。
- **平滑渐变无缝响应**：在任何二级子页面切换夜间/浅色模式时，界面平滑过渡，页面路由深度完整保留，绝不跳回首页。

### 4. 模型子目录沙盒隔离架构 (Model Sandboxing)
- **子目录沙盒化管理**：各模型独立归集至专属子目录（如 `models/sensevoice_small/`、`models/paraformer_zh/`、`models/pyannote/` 等），实现模型资产的物理隔离。
- **一键干净卸载**：提供专属删除方法，清理模型只需移除子目录，绝无孤儿权重与文件命名冲突残留。
- **向前平滑兼容**：内置智能探测器，优先读取沙盒目录，若未迁移则自动回退识别旧版根目录文件，老用户升级无需重新下载已有模型。

### 5. SQLite 高并发 WAL 引擎调优 (Write-Ahead Logging)
- **读写互不阻塞**：显式开启 SQLite `WAL` 模式与 `synchronous = NORMAL`，使后台密集段落入库与前台 FTS5 全文搜索并发执行，彻底杜绝 `database is locked` 锁库异常。
- **内存优化配置**：将临时排序与全文索引运算置于内存空间，大幅提升十万字级长会议检索效率。

### 6. 推理 Isolate 生命周期守护与空闲休眠 (Auto-Suspend & Watchdog)
- **空闲自动休眠与显存回收**：任务队列空闲超 3 分钟后，自动通知子 Isolate 安全卸载大型 ONNX 模型实例，**待机显存与内存从 300MB+ 直降至 40MB**，极大降低移动端后台被系统杀掉的概率。
- **看门狗崩溃自愈 (Watchdog)**：有新任务或录音时 500ms 快速拉起预热；若底层遭遇偶发段错误或不可抗力导致线程中断，看门狗自动捕获并无感重生，主 App 永不崩溃闪退。

### 7. 长音频流式批处理节流写入管线 (Throttled Commit Pipeline)
- **节流批量入库**：转写主循环引入滑动时间窗批处理写入器，每 3 句或每 350ms 聚合批量落库一次，磁盘 IO 频次下降 80%。
- **消除 UI 刷新抖动**：实时呈现连贯流畅的打字机般上屏效果，极大降低高频全局广播引起的界面微卡顿。

### 8. 全局设计规范：声明式 `ThemeExtension` 调色板
- 遵循 Flutter 官方标准实现 `PolyScribePalette extends ThemeExtension<PolyScribePalette>`，全面废除对全局静态变量 `AppColors.isDark` 的依赖，消除主题同步死角。
