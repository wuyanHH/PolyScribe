# PolyScribe (声织纪要) v0.1.0-beta.3 发版说明

PolyScribe `v0.1.0-beta.3` 针对近期用户的核心痛点反馈，带来了一系列深度体验打磨与功能闭环升级，并正式推出面向主流 64 位设备的 **Android ARM64-v8a (v8)** 专属优化安装包与 **Windows x64** 绿色版本。

---

## 🚀 核心更新亮点

### 1. 已有纪要一键重新转写 (Full Reprocessing Support)
- **播放详情页 (`SyncPlayerScreen`)**：AppBar 更多操作中新增「重新转写此纪要」与防误触确认弹窗，一键重置当前纪要为待转写状态并自动唤起后台推理引擎重新识别。
- **批量导入中心 (`BatchImportScreen`)**：已完成任务卡片均提供「重新转写」便捷操作通道，方便对历史音频进行重新解析。
- **主页列表 (`HomeScreen`)**：列表卡片操作菜单全面对齐重置转写逻辑，重置后自动重新加入队列。

### 2. 全局轻量浮动胶囊通知 (AppToast)
- **彻底杜绝遮盖痛点**：弃用原生底部紧贴式 SnackBar，引入全新的全局轻量居中/浮动胶囊通知。
- **即时销毁、杜绝堆叠排队**：新通知发出时自动清除上一条残留，不再发生多层弹窗轮番轰炸。
- **智能避让底部控制栏**：针对播放详情页底部控制条，自动增加 96px 底部安全间距，阅读与操作互不干扰。

### 3. 纪要播放智能吸附解耦与 35% 视线黄金居中
- **自由翻阅历史对话**：用户主动上下滚动浏览历史对话时，系统智能解除强制滚屏锁定，彻底消除 2 秒强制拉回阻断阅读的困扰。
- **一键快捷归位**：视线脱钩时，右下角优雅悬浮显示 `[ ⬇ 回到当前播放 (分:秒) ]` 按钮，AppBar 同步提供「跟读吸附」状态切换按钮。
- **视线黄金居中**：采用视口 35% 黄金视线定位，彻底解决高亮段落超出视口上沿或下沿的显示缺陷。

### 4. 设置中心排版重构与三联微缩主题 Tab
- **视觉排版重构**：将「视觉外观与主题风格」提升为设置页首要功能区，优化选项层级与操作间距。
- **三联微缩视窗 Tab**：提供「跟随系统」、「浅色模式」、「深色模式」可视化拟态切换，配合 SQLite 轻量键值持久化与 Riverpod 3.x 全局响应，即点即生效。

### 5. 模型更新中心自适应视觉优化
- **智能就绪操作栏**：全部模型就绪时自适应展示「检查最新版本」，缺失模型时提供「一键补齐全部」。
- **状态徽章规范化**：卡片右侧依据就绪、下载中、解压中提供直观指示徽章，镜像源选择器升级为横向扁平仪表条。

### 6. 多架构打包发布
- **Android `arm64-v8a` (v8 架构)**：针对现代 64 位 Android 芯片独立分包编译，安装包体积减少约 50%，冷启动速度与 AI 运算效率显著提升。
- **Windows x64**：提供免安装绿色运行环境，原生集成 WASAPI 系统内录引擎。
