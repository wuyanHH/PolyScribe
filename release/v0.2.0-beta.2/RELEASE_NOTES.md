# PolyScribe (声织纪要) v0.2.0-beta.2 发版说明

PolyScribe `v0.2.0-beta.2` 是一次聚焦于**全新品牌视觉形象升级、优雅动态启动开屏、双端原生图标重构与纪要文本排版深度打磨**的体验强化版本。本次更新推出了专为 PolyScribe 设计的全新现代化品牌徽标（搭载自适应律动声波与光效），重构了冷启动渐变开屏动画并支持极速跳过机制，全面升级了 Android 自适应圆角矢量图标与 Windows 多级分辨率 ICO 资产，并持续优化了转写文本排版清洗引擎，全量 69 项自动化测试 100% 绿灯通过。

---

## 🚀 核心更新亮点

### 1. 全新现代化品牌徽标 (PolyScribe Brand Logo)
- **声波律动美学**：全新设计的 `PolyScribeLogo` 品牌微标，融合了多角色声纹谱线与音频编织意象，内置自适应声学律动动态效果与柔和微光渐变。
- **全场景响应式适配**：支持从 24px 迷你导航栏、42px 抽屉图标到 96px+ 巨幅展示，自适应深色/浅色模式与 PRO 专业标识。

### 2. 丝滑动态启动开屏 (SplashScreen)
- **告别冷启动黑白屏闪烁**：深度整合 Android 原生 `launch_background` 主题过渡与 Flutter 端优雅启动开屏，冷启动过程如丝般顺滑。
- **极速进入支持**：提供平滑的淡入淡出动画过渡，并在右上角提供「进入工作台」一键跳过通道，兼顾视觉享受与极速办公效率。
- **极窄屏自适应**：开屏布局经 320px/360px 极窄屏幕严苛测试，无任何溢出或变形。

### 3. 双端原生应用图标全套重构
- **Android 全分辨率与自适应图标 (Adaptive Icons)**：
  - 全新生成规范的 `ic_launcher`、`ic_launcher_foreground` 以及圆角 `ic_launcher_round` 图标。
  - 覆盖 mdpi、hdpi、xhdpi、xxhdpi、xxxhdpi 全部分辨率，并完美兼容 Android 8.0+ 动态矢量规范与原生桌面圆角遮罩。
- **Windows 高精度多级 ICO 资产**：
  - 重新制作高质量 Windows `app_icon.ico`，内嵌 16x16、32x32、48x48、256x256 等多尺寸位图，高分屏下桌面快捷方式与任务栏图标极致锐利。

### 4. 纪要文本排版清洗器 (`TranscriptCleaner`) 持续调优
- **标点排版美化**：优化转写文本段落结尾的标点自动归一化处理，消除中英混排时标点孤立悬挂问题。
- **口吃与语助词平滑**：进一步优化重复叠字和口语停顿词的智能平滑算法，阅读体验更加紧凑连贯。

### 5. 自动化测试套件扩充与质量门禁
- **用例扩充至 69 项**：新增品牌徽标与启动页状态切换测试（`splash_and_logo_test.dart`），全面覆盖窄屏防溢出与跳过逻辑。
- **100% 绿灯保障**：全量 69/69 项自动化测试全部通过，保证生产发版零回归风险。
