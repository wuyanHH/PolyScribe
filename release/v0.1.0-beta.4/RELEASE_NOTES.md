# PolyScribe (声织纪要) v0.1.0-beta.4 发版说明

PolyScribe `v0.1.0-beta.4` 是一次以**代码健康巡检、端侧性能突破与开放协议互通**为核心的全面升级。本次更新彻底重构了底层全文检索引擎，原生存入 OpenAI Whisper 协议标准 Multipart 报文解包器，全面治理了多处瞬态内存悬挂，并引入了输入防抖与高频播放渲染节流机制，同时提供面向主流设备的 **Android ARM64-v8a (v8)** 架构安装包与 **Windows x64** 绿色免安装运行环境。

---

## 🚀 核心更新亮点

### 1. FTS5 全文检索引擎语法重构与性能全面激活
- **修复语法降级漏洞**：彻底剔除 SQLite FTS5 不支持的前缀通配符，重构为特殊字符安全清洗与前缀短语精准匹配 `"$sanitized"*`。
- **倒排索引毫秒级响应**：消除原本静默退化为全表 LIKE 扫描的低效开销，大幅提升数十万字大篇幅长会议纪要的关键词全文秒搜体验。
- **无感多层兜底**：保留标准参数化 LIKE 模糊搜索作为优雅降级兜底，确保特殊中文字符与极端生僻词 100% 检索兼容。

### 2. OpenAI Whisper 协议标准 Multipart/form-data 深度解包
- **原生 HTTP 报文解包器**：新增专用 Multipart 边界与 MIME Headers 提取器，从原始请求流中精准提取纯净二进制音频数据与原始文件名。
- **无缝打通第三方 AI 生态**：无需任何额外代理或适配插件，直接全面兼容**沉浸式翻译**、**LobeChat**、**ChatGPT-Next-Web**、各大开源听书/阅读 App 及 Python `openai.audio.transcriptions` 标准 SDK。

### 3. 全面治理 7 处瞬态生命周期控制器悬挂
- **控制器生命周期安全闭环**：对主页任务重命名、实时会议发言人标注、播放器角色入库、段落文本校对、标题重命名以及声纹库新建与修改弹窗中的 7 处局部 `TextEditingController` 全面补齐 `finally { controller.dispose(); }`，彻底阻断长时间频繁使用下的内部侦听器和句柄悬挂。

### 4. 全局检索输入 250ms 防抖与防并发竞态
- **输入平滑防抖**：在主页历史看板与播放详情页的搜索输入框接入 250ms 轻量防抖，连续按键击键零延迟响应 UI，停止输入后精准触发单次数据库查询。
- **一致性防乱序竞态**：引入文本一致性异步拦截机制，彻底消除网络或数据库异步延迟导致的“旧结果覆盖新结果”乱序闪烁。

### 5. 音字同步播放高频位置刷新收敛
- **平滑节流优化**：在音频播放过程中，针对毫秒级高频位置回调，在相同段落内部执行 >= 80ms 平滑节流控制。
- **显著降低长纪要功耗**：消除每 50ms 一次的全局无意义重复整树重绘，在保持播放进度条与光标吸附极致丝滑的同时，显著降低端侧设备 CPU 与 GPU 占用。

### 6. 代码库深度瘦身与全量质量门禁
- **释放 46.9MB 磁盘占用**：安全清理早期调试遗留的冗余测试模型。
- **自动化测试 100% 绿灯**：新增 FTS5 语法容错与 Multipart 标准文件上传解包自动化测试，全量 50/50 项单元测试全部高质通过。
